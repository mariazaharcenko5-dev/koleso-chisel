# Колесо чисел

Интерактивная игра Марии Захарченко для знакомства гостей на празднике.

Девять команд по дню рождения, вращение колеса, задания, шуточные прогнозы, таймер, звуковое оформление и полноэкранный режим.

## Запуск

Откройте опубликованную страницу GitHub Pages либо скачайте `index.html` и откройте его в браузере. Вся графика и аудио встроены в HTML. Подключение к интернету после загрузки не требуется.

В настройках ведущей можно отключить отсутствующие команды, выбрать режим без повторов и настроить звук. Музыка и эффекты запускаются после первого нажатия. Кнопка «На весь экран» находится справа вверху; также работают клавиши F и M.
